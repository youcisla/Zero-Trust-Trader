# Audit 2026-11-11 — what was applied, and what was not

An independent 17-page audit of `main @ 5901e7e` raised 29 findings and a four-phase
plan. This is the disposition of each one, so the next reader does not have to
re-derive it. Nothing here is aspirational: every "applied" row was reproduced in
the tree first and is covered by a test that fails if it returns.

## Not applied, and why

| Finding | Why not, and what would close it |
| --- | --- |
| C1 — the bar outruns the evidence | This is the headline finding and it is a redesign, not a patch: a hypothesis registry (distinct symbol x family x side, counted once) plus an alpha-spending function for repeat looks. It changes what `trials_total` means and therefore every published bar, so it needs its own measurement pass on real ledger data before it ships. |
| C3 — everything is in-sample | Needs a walk-forward split in `tier3_deep`: estimate on the first 9,000 bars, gate on the last 6,000 with parameters frozen. The split is small; the acceptance test (a synthetic overfit must fail, a synthetic edge must pass) is the work. |
| 3.4 — the constants' own search is uncounted | `PROTOCOL.md` + a test that fails when a strategy constant is absent from it, plus a ±20% sensitivity sweep. |
| 3.5 / 3.6 — one spread, one broker, ten months | Cost-model v2 (rolling spread distribution, slippage stress) and bar archival with hashes. Both need data plumbing that does not exist yet. |
| C1's companion — PSR/DSR | Cheap and valuable, but it must be priced off the registry count, which is C1. |
| D7 — no tests on `/api/scan`, `/ws`, `/api/report` | The live checks above exercise all three; turning them into CI tests needs an in-process server harness (`tower::ServiceExt`) that this binary does not have yet. |
| D8 — blocking calls in async | The `stat` moved to `spawn_blocking`; the child spawn itself is still `std::process` because its handle is waited on from a plain thread on purpose. Moving it to `tokio::process` is the follow-up. |
| Phase 3 — packaging, mypy, per-module floors, Linux replay | A week of work each and none of it protects the thesis until C1/C3 land. |
